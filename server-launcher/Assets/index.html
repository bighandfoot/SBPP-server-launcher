One-time setup for Play

Browsers can't start programs by themselves, so Play needs a small helper on your PC.

Open Minecraft Server Jars, double-click setup-play-button.bat, then press Done.

Starting a server accepts the Minecraft EULA.

Server options

4 GB

Saved to run.bat as -Xms and -Xmx. Leave at least 2–4 GB free for Windows.

Where should server jars go?

Pick a location and a Minecraft Server Jars folder will be created inside it. Your Downloads folder is a good choice. You can change this later in Settings.
