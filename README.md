A simple, user-friendly desktop application to download, manage, and launch different versions of Minecraft servers (Spigot, Bukkit, Paper, Purpur).

## Installation & Running

Because this launcher is an independent tool, Windows SmartScreen may initially flag it as an unrecognized application. Follow these steps to run the application safely:

1. Download and open **`server-launcher.exe`**.
2. When the blue **"Windows protected your PC"** window pops up, click the **`More info`** link text.
3. The window will expand to show the application details. Click the **`Run anyway`** button that appears at the bottom.

## Features

### 1. Multi-Software Support
Easily view and download prebuilt jars across popular server platforms:
* **Spigot** (Mirrored via MCJars)
* **Bukkit**
* **Paper**
* **Purpur**

### 2. Version Manager
* Scroll through an organized list of release builds.
* One-click **`Download`** buttons directly fetch your selected server version.

### 3. Quick Actions
From your server control dashboard, you can use the options menu to quickly manage your server files:
* **Play:** Start up your server instantly.
* **Open Folder:** Jump straight to the server directory to edit plugins, `server.properties`, or world files.
* **More Options:** Access advanced configurations.
* **Delete:** Remove a server version build when you no longer need it.
